云枢开关 · 使用说明（v1.3.0）
================================

一句话：给「云枢 Yunshu（eagleyun SASE）」加一个开关 —— 菜单栏点一下就连上
公司内网；再点一下彻底断开、退出，并把它的守护进程禁用。

────────────────────────────────────────────
一、安装（约 30 秒）
────────────────────────────────────────────

1. 打开本磁盘映像，把左边的「云枢开关」拖到右边的「应用程序」；
2. 在「启动台」或「应用程序」里双击「云枢开关」；
   · 若提示「无法验证开发者」：在 App 上右键 →「打开」→「仍要打开」（只需一次）；
3. 菜单栏出现云朵图标，说明程序已在运行；
4. 首次运行有两个「一次性」授权，跟着弹窗做即可：
   ① 「欢迎使用云枢开关 · 还差一步配置」→ 点「立即配置」→ 输入一次开机密码
      （装的是免密提权助手，之后连接/断开都不再问密码）
   ② 「需要辅助功能权限」→ 点「打开系统设置」→ 在「辅助功能」里勾选「云枢开关」

这两步做完，日常使用全程不再弹任何窗口。

────────────────────────────────────────────
二、日常使用（菜单栏云朵图标）
────────────────────────────────────────────

  连接内网（启动并连接）   拉起守护进程 + 用户级代理 + 云枢主程序，并自动点「连接网络」
  断开并禁用（彻底退出）   断隧道 → 退程序 → 禁用 3 个守护进程（会二次确认）
  刷新状态 / 打开日志目录 / 一键修复 / 诊断导出

菜单第一行实时显示状态：已连接企业内网 / 已启动，未连接 / 已完全停用（每 8 秒刷新）。

────────────────────────────────────────────
三、命令行（可选，喜欢终端的用）
────────────────────────────────────────────

首次启动 App 时已自动把 ysctl 链接到 ~/.local/bin/ysctl。
若终端提示找不到命令，把下面这行加进 ~/.zshrc：

  export PATH="$HOME/.local/bin:$PATH"

  ysctl up               启动并连接
  ysctl down             断开 → 退出 → 禁用（问一次 y/N）
  ysctl down -y          同上，不问（推荐做别名）
  ysctl toggle           连着就断，断着就连
  ysctl status           详细状态
  ysctl state            只输出 connected / idle / off
  ysctl setup            安装免密助手（只需一次密码）
  ysctl fix              一键修复：免密规则 + 辅助功能 + 自检
  ysctl doctor           环境自检
  ysctl ax               打开「辅助功能」授权面板

建议在 ~/.zshrc 里加两个别名：

  alias ysu='ysctl up'
  alias ysd='ysctl down -y'

────────────────────────────────────────────
四、常见问题
────────────────────────────────────────────

· 每次连接/断开都要输密码
    → 免密助手没装好。菜单栏 →「一键修复（免密/授权）」，或终端执行 ysctl fix。

· 点了「连接内网」，云枢起来了但没连上
    → 冷启动的头几秒云枢界面还没准备好，第一次点击可能被它静默忽略。
      1.3.0 会自动补点，仍然不行会自动重启云枢再点一次。
      还不行就再点一次，或终端执行 ysctl up。

· 菜单栏图标点了没反应
    → 上一次操作多半卡在系统密码框里。等它超时收尾（最多 150 秒），再点一次。

· 菜单栏里找不到云朵图标
    → 菜单栏排满了。按住 ⌘ 拖动图标调整顺序，或隐藏几个不常用的图标后重开本工具。

· 想让工具开机自启
    → 系统设置 → 通用 → 登录项 → 点「+」，选「应用程序」里的「云枢开关」。

────────────────────────────────────────────
五、卸载（完全可逆）
────────────────────────────────────────────

  1. 菜单栏 →「连接内网」，先让云枢恢复正常（避免管理后台显示离线）；
  2. 终端执行：ysctl unsetup        （移除免密助手）
  3. 把「应用程序」里的「云枢开关」拖进废纸篓；
  4. 可选：删除 ~/Library/Logs/YunshuSwitch 与
     ~/Library/Application Support/YunshuSwitch

────────────────────────────────────────────
六、注意事项（重要）
────────────────────────────────────────────

· 云枢是公司管控软件。禁用后设备在管理后台会显示离线，可能触发合规告警，
  请在公司制度允许的范围内使用；
· 「断开并禁用」会立刻切断内网，正在跑的内网任务（拉代码、连数据库）会中断；
· 把机器交给 IT 排障前，先点「连接内网」恢复；
· 本工具不改动云枢安装包、不做破解，只操作 launchd 的启用/禁用状态，随时可还原；
· 日志：~/Library/Logs/YunshuSwitch/（ysctl.log 命令行、app.log 菜单栏）。
